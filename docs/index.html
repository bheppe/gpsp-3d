gpSP 3D

Game Boy Advance games in stereoscopic 3D on the Nintendo 3DS, with every background layer and sprite at its own depth. Its sibling, Snes9x 3D, does the same for SNES games.

Install with Universal-Updater

In Universal-Updater, open Settings → Select a UniStore → + and scan this QR code, or enter the address below. The store has gpSP 3D, Icon Maker and Snes9x 3D, and tells you when there are updates.
